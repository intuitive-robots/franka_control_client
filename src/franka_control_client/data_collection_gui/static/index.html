How the timeline is built

Frame k of the dataset is the grid time t0 + k / fps over the robot timestamps; it takes the latest robot sample at or before that time and from each camera the latest frame captured up to that sample. Recordings from this GUI store per-frame camera timestamps; older recordings are assumed to spread their frames evenly (or set the camera rate). Action leader: GELLO joints / VR pose / replayed command at the same sample. next state: the follower state of the next frame (kinesthetic demos). Images keys drop the zed_ prefix like the existing converters.
